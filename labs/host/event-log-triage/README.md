# Windows 事件日志时间线研判

## 实验目标

使用固定脱敏异常登录、特权组变更、服务安装和维护基线进行两步时间线研判，练习从孤立事件判断转向身份与服务证据关联。

## 前置条件

- 本机前后端服务已启动，并使用项目演示账号登录。
- 只使用工作台提供的固定相对时间线和决策选项。
- 不连接 Event Viewer、注册表、服务控制管理器、真实主机或外部日志平台。

## 使用方式

1. 在风险观察版运行“孤立信任单条事件 → 忽略身份与服务关联”路径。
2. 在防御复盘版运行“关联身份与服务事件 → 升级调查”路径。
3. 载入正常维护路径，确认登记维护事件可以凭固定基线关闭。
4. 对照 `host-event-log-triage-risk-accepted`、`host-event-log-triage-defense-blocked` 和 `host-event-log-triage-normal-verified`。

## 安全边界

该实验按 case-study 边界运行，只读取仓库内固定脱敏数据，不读取或处置真实 Windows 状态，不提供 `exploit.py`、查询脚本或主机操作能力。
