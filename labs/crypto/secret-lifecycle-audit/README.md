# 秘密泄露与密钥生命周期审计

## 实验目标

使用固定秘密标记和虚构密钥台账，对比跳过审计、吊销轮换和活动版本正常发布三条路径。固定配置、日志、源码和制品清单只含 `virtual-secret-marker-*`，密钥台账只含虚构 ID 与状态。

## 前置条件

- 本机前后端服务已启动，并使用项目演示账号登录。
- 只使用工作台返回的固定标记、虚构台账和决策选项。
- 不向页面或 API 提交任何真实密码、token、证书、密钥或凭据。

## 使用方式

1. 在风险观察版运行“不扫描直接发布 → 继续使用暴露静态密钥”路径。
2. 在防御复盘版运行“扫描固定制品 → 吊销、轮换并改用注入秘密”路径。
3. 载入活动版本正常发布路径，确认生命周期控制不会阻断合规版本。
4. 对照三个 canonical 信号以及事件日志中的固定计数和终止结果。

## 安全边界

实验不读取 `.env`、Git 历史、真实日志、源码目录或构建产物，不生成、存储、校验或传输真实密钥材料。
