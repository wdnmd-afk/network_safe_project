# 点击劫持风险观察步骤

本实验已在 LT-006 专用化为两步决策交互，漏洞路径需要依次选择框架策略与敏感动作。

1. 登录本机学习平台。
2. 打开 `/labs/web/clickjacking/vuln`。
3. 第 1 步“框架嵌入策略”选择“允许任意来源嵌入（漏洞视角）”，观察框架被打开信号 `web-clickjacking-frame-open`。
4. 第 2 步“敏感动作确认”选择“无二次确认直接执行（漏洞视角）”。
5. 点击“运行固定评估”，提交固定案例 `embedded-approval-overlay` 与决策路径。
6. 观察终止决策 `accepted`、学习信号 `web-clickjacking-risk-accepted` 和结果计数。
7. 在统一事件日志中确认只记录固定案例 key、决策路径信号和安全摘要。

该流程只观察固定本机教学结果，页面只提供固定决策按钮，不提供真实框架地址、页面正文或外部目标操作步骤。
