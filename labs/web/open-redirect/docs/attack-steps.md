# 开放重定向风险观察步骤

本实验为两步决策交互：先选择跳转目标来源策略，再选择重定向处置方式。

1. 登录本机学习平台。
2. 打开 `/labs/web/open-redirect/vuln`。
3. 第一步“跳转目标来源”选择“直接信任外部输入的目标”，观察 `web-open-redirect-target-open`。
4. 第二步“重定向决策”选择“未校验直接重定向”。
5. 点击“运行固定评估”。
6. 观察终止决策 `accepted`、学习信号 `web-open-redirect-risk-accepted` 和风险标签。
7. 在统一事件日志中确认只记录固定 key、决策路径信号和安全摘要。

该流程只观察固定本机教学结果，页面只提供固定决策选项，不提供真实跳转地址、外部 URL 或页面正文，也不提供外部目标操作步骤。
