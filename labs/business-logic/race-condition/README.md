# 业务竞态与幂等

## 实验目标

固定资源库存为 1，两个固定请求读取同一版本。实验对比无锁双扣、幂等/版本阻断和单次唯一请求正常通过。

## 前置条件

- 本机前后端服务已启动，并使用项目演示账号登录。
- 只使用工作台内置的固定库存、版本、请求和决策选项。
- 不运行并发压测，不连接真实订单、库存、资金或数据库事务。

## 使用方式

1. 在风险观察版运行“无版本校验 → 接受两次扣减”路径。
2. 在防御复盘版运行“幂等与版本校验 → 阻断重复或陈旧请求”路径。
3. 载入正常唯一请求路径，确认修复后仍可完成一次合法扣减。
4. 对照 `business-logic-race-condition-risk-accepted`、`business-logic-race-condition-defense-blocked` 和 `business-logic-race-condition-normal-verified`。

## 安全边界

实验只生成固定教学摘要，不接收商品 ID、金额、库存或幂等值，也不发起真实并发或重放请求。
