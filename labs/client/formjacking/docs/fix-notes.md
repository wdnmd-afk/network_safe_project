# Formjacking 修复说明

## 根因

敏感页面信任未受约束的第三方脚本和提交目标，脚本可在运行时改写敏感表单的提交目标。

## 修复策略（两步固定决策）

- 第 1 步启用“CSP、SRI 与脚本清单”，未登记或被篡改的第三方脚本无法加载或执行。
- 第 2 步防御拦截被篡改提交目标，或在第一方目标校验通过后放行正常结账。
- 未知 `scenarioKey` 或未登记决策 `optionKey` 必须脱敏阻断且不回显原始值。
- 事件日志只记录固定 key、决策路径信号、结果计数和后端决策。
- 正常受控流程必须通过“提交到已校验的第一方目标”验证，不得一刀切破坏正常业务。

## 生产补充

真实生产环境还需要结合资产、身份、网络、终端、供应商和应急响应体系实施分层防护；本实验结果不能替代生产安全评估。
