# API 功能级授权修复说明

## 根因

管理操作只在前端隐藏，服务端缺少功能级授权校验，普通用户可直接调用管理接口越权执行。

## 修复策略

- 验证落实“服务端功能级授权、最小权限和审计”后的正常受控流程。
- 每个敏感操作在服务端按角色/权限矩阵校验，不依赖前端隐藏或客户端角色判断。
- 未知 `scenarioKey` 或决策 `optionKey` 必须阻断且不回显原始值。
- 事件日志只记录固定 key、风险标签、后端决策和学习信号。
- 正常受控流程必须通过“服务端功能级授权已启用”校验，管理员身份确认后放行，不得一刀切破坏正常业务。

## 生产补充

真实生产环境还需要结合统一鉴权中间件、集中式策略、权限矩阵测试和审计告警实施分层防护；本实验结果不能替代生产安全评估。
