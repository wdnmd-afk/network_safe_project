# 凭据填充风险观察步骤

本实验为两步决策交互，漏洞路径演示“只判断单次口令 + 无挑战放行”如何接受批量登录。

1. 登录本机学习平台。
2. 打开 `/labs/auth/credential-stuffing/vuln`。
3. 固定案例为“重复凭据登录批次”，只含统计摘要，不含真实账号或口令。
4. 第 1 步（风险关联策略）选择“只判断单次口令结果（漏洞视角）”，观察 `auth-credential-stuffing-correlation-open`。
5. 第 2 步（挑战决策）选择“无挑战直接放行（漏洞视角）”，观察终止信号 `auth-credential-stuffing-risk-accepted`、决策 `accepted` 和风险标签。
6. 也可点击“载入推荐路径”一次载入完整风险决策路径。
7. 在统一事件日志中确认只记录固定 case key、决策路径信号和结果计数，不记录原始输入。

该流程只观察固定本机教学结果，不提供外部目标、真实凭据或可迁移的攻击操作链。
