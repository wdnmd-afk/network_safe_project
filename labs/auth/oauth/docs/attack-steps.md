# OAuth 漏洞风险观察步骤

1. 登录本机学习平台。
2. 打开 `/labs/auth/oauth/vuln`。
3. 固定案例为“授权响应关联缺失”（scenarioKey `tampered-authorization-response`）。
4. 第 1 步授权绑定策略：选择“接受未绑定授权响应”。
5. 第 2 步授权响应决策：选择“直接接受被篡改授权响应”。
6. 点击“运行固定评估”。
7. 观察两步决策路径、终止决策 `accepted` 和学习信号 `auth-oauth-risk-accepted`。
8. 在统一事件日志中确认只记录固定 key、决策路径信号和安全摘要。

该流程只观察固定本机教学结果，页面只提供固定决策选项，不接受真实回调地址、授权码、token 或外部目标，也不提供外部目标操作步骤。
