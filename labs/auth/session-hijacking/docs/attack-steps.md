# 会话劫持风险观察步骤

本实验已在 LT-009 专用化为两步决策交互（上下文绑定策略 → 会话处置决策）。

1. 登录本机学习平台。
2. 打开 `/labs/auth/session-hijacking/vuln`。
3. 步骤一「上下文绑定策略」选择“信任长期有效会话（漏洞视角）”。
4. 步骤二「会话处置决策」选择“直接接受被复用会话（漏洞视角）”。
5. 点击“运行固定评估”。
6. 观察终止决策 `accepted`、学习信号 `auth-session-hijacking-risk-accepted` 和逐步结果。
7. 在统一事件日志中确认只记录固定 scenarioKey、决策路径信号和结果计数。

该流程只观察固定本机教学结果，页面只提供固定决策按钮，不接受真实会话标识、Cookie、token 或外部目标。
