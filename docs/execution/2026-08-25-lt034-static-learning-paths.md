# LT-034 静态学习路径与前后关系执行文档

## 1. 目标

实现首批静态学习路径、前置实验和推荐后续关系，复用当前实验 ID 与现有目录/详情页面，不新增数据库表或平行内容源。

## 2. 固定路径

- Web 应用基础：XSS、CSRF、SQL 注入、文件上传、SSRF。
- 认证与访问控制：暴力破解、会话固定、JWT、IDOR、权限提升、API 功能级授权。
- 网络防御：端口暴露、DNS 劫持、MITM、DDoS。
- 供应链完整性：依赖混淆、恶意包、更新投毒。
- AI 安全：Prompt 注入、Deepfake、对抗性 AI。

每条路径是有序现有实验 ID 列表，附 `beginner` / `intermediate` / `advanced` 标签；前置与后续关系由相邻节点确定。

## 3. 操作步骤

1. 新增静态路径定义、schema 校验和查询纯函数。
2. 在 LabsView 展示路径选择与有序实验入口。
3. 在 LabDetailView 展示所属路径、前置实验和推荐下一项。
4. 对未知/重复实验 ID、空路径和关系查询增加测试。

## 4. 风险、优化与验证

- 路径只引用当前元数据 ID，不把未注册主题伪装成可学习入口。
- 同一实验可被多条路径引用；详情按稳定顺序展示所有上下文。
- 验证：路径定义测试、目录/详情测试、类型检查、代表性 Playwright、`pnpm verify`。

## 5. 完成条件

- 五条路径均可从目录进入，详情页可查看准确前置和后续关系。
- 不修改元数据 schema 或数据库，所有引用通过一致性测试。

## 6. 验证结果（2026-08-27）

- 5 条路径引用、重复/未知 ID 和前后关系测试通过；前端类型检查通过。
- 目录有序入口与实验详情前置/后续关系 E2E 通过；根级 `pnpm verify` 通过。
