# LT-033 实验目录筛选与搜索执行文档

## 1. 目标

在现有 `LabsView` 实现分类、难度、模式、风险、深度筛选，以及对 `title`、`summary`、`tags`、`knowledgePoints` 的全文/知识点搜索。

## 2. 字段与范围

- 直接字段：`category`、`difficulty`、`mode`、`severity`。
- 搜索字段：`title`、`summary`、`tags`、`knowledgePoints`。
- 深度字段不写入元数据；按覆盖矩阵同一规则派生：引导式目录内为 D2，非引导式 `interactive` 为 D4，其余为 D3。
- 纯前端过滤已加载的固定元数据，不新增后端自由查询接口。

## 3. 操作步骤

1. 新增目录筛选纯函数与稳定选项模型。
2. 在实验目录加入搜索框和五组菜单筛选。
3. 展示匹配数量、清除筛选和空结果状态。
4. 保持分类分组、详情和变体入口行为不变。
5. 增加搜索字段、组合筛选和深度派生测试。

## 4. 风险、优化与验证

- 搜索只做小写子串匹配，不接受正则，不索引事件日志或用户输入。
- 控件采用紧凑工作台布局，不新增卡片嵌套或营销式内容。
- 验证：前端单元测试、类型检查、代表性 Playwright、`pnpm verify`。

## 5. 完成条件

- 六类条件可组合，结果与固定元数据一致，移动端不溢出。
- 无搜索条件时保持现有完整目录，测试和门禁通过。

## 6. 验证结果（2026-08-27）

- 目录筛选与搜索纯函数测试通过；前端全量为 80 个测试文件、285 项测试通过。
- Web 类型检查、目录搜索/深度筛选 E2E 和根级 `pnpm verify` 均通过。
