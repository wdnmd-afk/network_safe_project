## 1. 文档定位

本文档承接 `SECURITY-COVERAGE-LONG-TERM-GOAL.md` 第 9.6 节和阶段 5，用于在进入实现前确认检测响应与安全运营首批实验的分类、目录、元数据字段、接口结构、固定数据集和安全边界。

检测响应方向与其他方向的关键差异：它以“固定安全事件数据集”为核心资产，多个实验共享同一份脱敏事件数据，因此需要先设计统一事件数据模型，再逐个落地分析实验。

## 2. 规划原则

- 先建立统一固定安全事件数据集，再让检测、研判、处置类实验共享消费。
- 只使用固定脱敏事件数据，不接入真实 SIEM、真实日志源或外部威胁情报。
- 不执行外部查询、不运行真实检测引擎、不使用真实恶意样本。
- 复用统一 `lab_event_logs` 记录学习交互；固定安全事件数据集独立于平台运行日志，仅作教学素材。
- 检测响应实验优先以 `simulation`（状态/时间线观察）或 `case-study`（决策复盘）表达，不追求真实攻击能力。

## 4. 首批候选清单

取“统一数据集 + 两个高价值分析实验”作为首批，先打地基再做分析。

| 顺序 | 实验 | 分类 | 建议模式 | 依赖 | 结构性价值 |
|---|---|---|---|---|---|
| 1 | 统一固定安全事件数据集 | `detection`（共享资产） | 数据集 + 校验 | 无 | 为后续检测响应实验提供单一脱敏数据源 |
| 2 | 固定检测规则匹配与误报/漏报分析 | `detection` | `simulation` | 数据集 | 补规则命中、误报、漏报的可观察差异 |
| 3 | 告警分级、证据确认与处置决策 | `detection` | `case-study` | 数据集 | 补告警优先级、证据链和处置决策复盘 |

说明：

- Sigma / YARA 风格学习作为规则实验的固定素材形态，不新建独立引擎，也不执行真实规则。
- 事件时间线、隔离/冻结/轮换处置决策在“处置决策”实验中以固定分支决策表达。

## 5. 统一固定安全事件数据集设计

### 5.1 数据模型（LT-024 已确认）

固定事件条目字段（全部为脱敏虚构值）：

- `eventId`：固定事件标识（kebab-case）。
- `timestamp`：相对时间戳（固定序列，用于时间线排序，不含真实时间）。
- `source`：`virtual-auth-service` | `virtual-endpoint` | `virtual-network-sensor`。
- `category`：`auth` | `process` | `network` | `file`。
- `severity`：`low` | `medium` | `high` | `critical`。
- `signalTags`：固定风险标签数组。
- `summary`：固定脱敏摘要，不含真实主机名、账号、IP 或凭据。
- `expectedDisposition`：`benign` | `suspicious`，作为确定性计算误报和漏报的教学基线。

数据集固定放在 `packages/shared/src/fixed-security-events.js`，key 为 `fixed-auth-process-alert-timeline`，由同名 `.d.ts`、校验器和共享测试约束。

### 5.2 边界

- 数据集为静态固定内容，不从真实系统采集，不含任何真实 PII、凭据或网络标识。
- 数据集作为共享只读素材，检测/研判实验只引用其 `eventId` 与固定字段，不改写。

## 6. 每个候选的固定模型与边界

### 6.1 固定检测规则匹配与误报/漏报分析

- 固定案例：一组固定事件 + 一组固定规则，观察命中、误报、漏报分布。
- 状态机 / 观察：规则过宽（大量误报）→ 规则过窄（漏报）→ 平衡规则（准确命中）。
- 边界：规则只登记固定 `ruleProfileKey` 与 `matchedEventIds`，不保存、解析或执行真实查询表达式。

### 6.2 告警分级、证据确认与处置决策

- 固定案例：一条固定告警时间线，包含证据卡与影响面。
- 两步决策：分级策略（按单指标 vs 多证据关联）→ 处置决策（忽略 / 隔离冻结 / 正常放行并记录）。
- 边界：处置为固定决策枚举，不执行真实隔离、冻结或流量阻断。

## 8. 安全边界总纲

- 只使用固定脱敏虚构事件数据、内存状态机与枚举决策，不接入真实 SIEM、日志源、威胁情报或恶意样本。
- 不执行外部查询、真实检测引擎、真实规则匹配器或真实处置动作。
- API 与页面只接受注册过的固定 key，未知 key 脱敏阻断且不回显原始输入。
- 事件日志只记录固定 key、步骤、决策、信号和安全摘要。
