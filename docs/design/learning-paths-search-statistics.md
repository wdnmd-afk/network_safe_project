## 1. 文档定位

本文档承接 `SECURITY-COVERAGE-LONG-TERM-GOAL.md` 第 7.2、7.3 节，用于在进入实现前确认学习路径、目录搜索筛选和长期学习统计的数据来源、接口结构、前端形态和安全边界。

本文档保留原规划约束；`LT-033` 与 `LT-034` 已按独立执行文档完成首批实现，后续统计扩展仍需单独切片。

## 2. 规划原则

- 复用现有 `labs/**/meta.json`、`lab_event_logs`、学习进度、验证记录和复盘题完成记录，不新建平行数据源。
- 路径、筛选和统计只读现有数据派生，不改变实验元数据 schema（除非另行确认）。
- 统计只使用学习结果和安全摘要，不导出原始输入、凭据、外部目标或自由文本。
- 前端复用现有 `LabsView`、`LabDetailView`、`AccountView` 与平台状态页，不另起入口。
- 学习路径顺序基于覆盖矩阵的分类、深度等级和前置关系，不引入外部内容。

## 4. 首批候选切片

优先级取"低风险、纯派生、可复用现有数据"的三项作为首批。

| 顺序 | 功能 | 数据来源 | 形态 | 结构性价值 |
|---|---|---|---|---|
| 1 | 目录筛选（分类/难度/模式/风险/深度） | 元数据 + 覆盖矩阵 | `LabsView` 前端筛选 | 让 65 个实验可按维度快速定位 |
| 2 | 知识点与全文搜索 | 元数据 title/summary/tags/knowledgePoints | 前端索引 + 轻量后端查询 | 按关键词与知识点检索实验 |
| 3 | 学习路径与前置/后续关系 | 覆盖矩阵分类 + 深度等级 | 路径视图 + 详情前置提示 | 按 Web/认证/网络等路径顺序学习 |

说明：

- 全文搜索首批只索引固定元数据字段，不索引事件日志或用户输入。
- 学习路径首批以只读静态定义表达（分类内按深度和前置排序），是否落库另行确认。

## 5. 每个候选的模型与边界

### 5.1 目录筛选

- 维度：分类、难度、模式、风险、深度等级（深度来自覆盖矩阵）。
- 形态：`LabsView` 增加多维筛选控件，纯前端对已加载元数据过滤。
- 边界：只过滤现有元数据字段，不新增后端查询参数或自由文本。

### 5.2 知识点与全文搜索

- 索引字段：`title`、`summary`、`tags`、`knowledgePoints`。
- 形态：前端构建轻量索引；如需后端查询，只接受固定字段与关键词，不接受正则或原始 SQL。
- 边界：不索引事件日志、用户笔记或任何原始输入。

### 5.3 学习路径与前置/后续

- 模型：每条路径是有序实验 id 列表，附初级/中级/高级标签和前置实验 id。
- 形态：路径视图列出路径与进度；详情页展示前置和推荐后续实验。
- 边界：路径只引用现有实验 id，不引入外部内容或未注册实验。

### 5.4 长期统计（后续切片）

- 指标：分类完成度、连续学习、常见误判、检测确认时间（检测响应实验就绪后）。
- 数据来源：事件日志安全摘要 + 学习进度 + 复盘完成记录。
- 边界：只统计计算后的安全摘要，导出默认只含学习结果，不含原始输入或凭据。

## 6. 统一产物要求

每项功能实现时应具备：

- 明确的只读数据来源与派生逻辑，不改动实验元数据 schema（除非另行确认）。
- 前端复用现有视图与组件，新增组件保持深色安静主题与无障碍。
- 后端如新增查询接口，只接受固定字段与枚举，不接受自由文本或原始查询。
- 受影响范围单元/组件测试与类型检查。
- 独立执行文档。

## 8. 安全边界总纲

- 只读现有元数据、事件日志安全摘要、学习进度和复盘记录派生，不改变已发生的学习事实。
- 搜索与统计不索引或导出原始输入、凭据、外部目标、Cookie、token 或自由文本。
- 后端查询接口只接受固定字段与枚举，未知参数忽略或阻断，不回显原始输入。
- 前端筛选与路径只引用现有实验 id 与元数据字段，不引入外部内容。
