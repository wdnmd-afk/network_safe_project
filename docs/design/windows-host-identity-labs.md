## 1. 文档定位

本文档承接 `SECURITY-COVERAGE-LONG-TERM-GOAL.md` 第 9.4 节和阶段 4，用于在进入实现前确认 Windows 主机与身份基础设施首批实验的分类、目录、元数据字段、接口结构和安全边界。

本项目定位为 Windows 本机学习平台，主机与身份方向是其差异化价值。但所有实验只使用固定虚构数据，不读取、修改或连接真实主机、文件系统 ACL、系统凭据或目录服务。

本文档只做规划，不实现任何实验。每个实验进入实现前仍必须单独编写执行文档，并按第 14 节切片流程推进。

## 2. 规划原则

- 只使用固定虚构权限描述、服务配置、事件数据、令牌差异和虚拟资产关系图。
- 不读取真实文件系统 ACL、注册表、系统凭据、真实事件日志或域控信息。
- 不创建真实计划任务、服务、启动项或提权操作。
- 高风险主机主题优先用 `simulation`（固定状态观察）或 `case-study`（证据研判决策），不发展真实提权或横向移动能力。
- 复用第二版引导式状态机与既有专用实验样板表达多步骤固定决策。

## 5. 每个候选的固定模型与边界

### 5.1 Windows 服务权限与不安全服务路径

- 固定案例：某虚构服务以高权限运行且可执行文件路径可被低权限用户写入或路径未加引号。
- 两步决策：路径与权限策略（保留可写路径 vs 收敛 ACL 与加引号路径）→ 处置（越权替换接受 / 阻断 / 正常受控运行）。
- 边界：只使用固定服务配置描述字符串，不枚举或修改真实服务与 ACL。

### 5.2 计划任务与启动项持久化研判

- 固定案例：固定持久化时间线出现异常启动项与计划任务注册意图。
- 证据研判：识别可疑持久化 → 隔离/移除决策 → 正常受控自启项确认。
- 边界：只展示固定事件卡，不创建、修改或删除真实计划任务与启动项。

### 5.3 Windows 事件日志研判

- 固定案例：固定脱敏事件序列（异常登录、权限变更、服务安装）。
- 证据研判：告警分级 → 关联根因 → 处置优先级与升级决策。
- 边界：只使用固定脱敏事件数据，不读取真实 Windows 事件日志。
- LT-039 实现 ID 为 `host.event-log-triage`，固定案例为 `fixed-windows-identity-service-timeline`。
- 复用共享固定事件 schema，新增虚构 Windows Security Log 与服务管理器来源；元数据保持 `in-progress`，等待命令验证。

### 5.4 横向移动路径分析

- 固定案例：虚拟资产关系图中某节点凭据可达多台高价值节点。
- 状态机：过度互信接受 → 分段/凭据边界识别 → 正常最小可达确认。
- 边界：只使用内存虚拟资产图，不扫描、连接或认证到真实主机。

- 只使用固定虚构权限、配置、事件和虚拟资产图，不读取或修改真实主机状态。
- 不读取真实文件系统 ACL、注册表、系统凭据、真实事件日志或域控信息。
